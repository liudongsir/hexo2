springboot初始属性几种方式

发表于2026-03-13|更新于2026-03-13|springboot
|字数总计:752|阅读时长:3分钟|阅读量:

springboot初始属性几种方式

一、Spring 官方推荐的 5 种初始化方式

1️⃣ 实现 InitializingBean 接口（Spring 原生）

重写 afterPropertiesSet() 方法，属性注入完就执行。

@Component
public class MyBean implements InitializingBean {
    @Override
    public void afterPropertiesSet() {
        // 初始化逻辑
        System.out.println("Bean 初始化完成！");
    }
}

2️⃣ **@Bean (initMethod = “方法名”)**（配置类专用）

在配置类里注册 Bean 时指定初始化方法。

@Configuration
public class Config {
    @Bean(initMethod = "init")
    public MyService myService() {
        return new MyService();
    }
}

public class MyService {
    public void init() {
        // 初始化
    }
}

3️⃣ 构造方法初始化（最早期）

Spring 4.x+ 推荐，依赖注入 + 初始化一起做。

@Service
public class UserService {
    private final UserRepository repo;

    // 构造方法执行时就可以做初始化
    public UserService(UserRepository repo) {
        this.repo = repo;
        this.init(); // 自己调用
    }

    private void init() {
        // 初始化
    }
}

4️⃣ ApplicationListener

容器完全启动成功后执行（所有 Bean 都创建好了）。==利用springboot晟敏周期事件==

@Component
public class StartupListener implements ApplicationListener<ContextRefreshedEvent> {
    @Override
    public void onApplicationEvent(ContextRefreshedEvent event) {
        // 容器启动完成 → 执行初始化
    }
}

5️⃣ @EventListener(ContextRefreshedEvent.class)

@Component
public class StartupRunner {
    @EventListener(ContextRefreshedEvent.class)
    public void init() {
        // 容器启动完成执行
    }
}

二、Spring Boot 专用（非常常用）

6️⃣ CommandLineRunner

项目启动成功后立即执行。

@Component
public class MyRunner implements CommandLineRunner {
    @Override
    public void run(String... args) {
        // 启动后初始化
    }
}

7️⃣ ApplicationRunner

和上面一样，只是参数更强大。

@Component
public class AppStartup implements ApplicationRunner {
    @Override
    public void run(ApplicationArguments args) {
        // 启动后初始化
    }
}

三、最底层：BeanPostProcessor

你刚才问的那个！可以在初始化前后插手。==bean生命周期==

@Component
public class MyBeanPostProcessor implements BeanPostProcessor {
    @Override
    public Object postProcessAfterInitialization(Object bean, String beanName) {
        // Bean 初始化之后执行
        return bean;
    }
}

四、执行顺序（超级重要！面试必问）

从早到晚顺序：

  1. 构造方法
  2. 属性注入
  3. InitializingBean#afterPropertiesSet()
  4. @PostConstruct
  5. @Bean(initMethod)
  6. 初始化完成
  7. ContextRefreshedEvent（容器刷新）
  8. CommandLineRunner / ApplicationRunner（项目启动完成）

五、一句话总结（你记这个就够）

  • @PostConstruct → 最常用
  • InitializingBean → Spring 原生
  • initMethod → 配置类专用
  • ContextRefreshedEvent → 容器启动完执行
  • CommandLineRunner → 项目启动完执行

六、一句话终极记忆（工作直接用）

  1. 自己的 Bean 初始化 → @PostConstruct（第 3 位）
  2. 第三方 Bean 初始化 → initMethod（第 5 位）
  3. 全局容器操作（全 Bean 就绪） → ContextRefreshedEvent（第 7 位）
  4. 项目启动完执行任务 → CommandLineRunner（第 8 位）

总结

  1. 执行顺序固定：构造 → 注入 → @PostConstruct → InitializingBean → initMethod → 容器刷新 → 启动完成
  2. 核心规则：资源越全局，执行位置越靠后
  3. 业务首选：**@PostConstruct**（自身初始化）+ CommandLineRunner（启动后任务）
